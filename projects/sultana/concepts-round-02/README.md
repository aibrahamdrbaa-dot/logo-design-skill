# سلطانة — الاتجاه A | الجولة الثانية

**الحالة:** مسودة مطوّرة للمراجعة والاعتماد، وليست هوية نهائية معتمدة.

## الفكرة
الاسم العربي هو مركز العلامة. اخترنا خلفية عاجية دافئة، وكتابة بلون بني حبر، ولمسة شامبانيا هادئة في فاصل هندسي بسيط. أضفنا وصف «صالون شعر وأظافر» لتوضيح النشاط، دون استخدام تاج أو مقص أو أيقونة تجميل نمطية.

## الملفات
- `sultana-wordmark.svg`: النسخة القابلة للتحرير (تعتمد على خطوط Amiri وNoto Sans Arabic).
- `sultana-wordmark-outlined.svg`: نسخة مسارات متجهية، لا تتطلب تثبيت الخطوط.
- `sultana-wordmark-transparent.svg` و`sultana-wordmark-transparent.png`: نسخة بخلفية شفافة.
- `sultana-wordmark-dark.svg` و`sultana-wordmark-dark.png`: نسخة على خلفية داكنة.
- `preview.png`: المعاينة الرئيسية.

## الفحص البصري
- صُيّرت النسخة الفاتحة والداكنة عبر Inkscape ورُوجعت بصرياً.
- الاسم «سلطانة» مقروء بالعربية، والاسم هو العنصر البصري الأبرز.
- تم فحص المساحة حول العلامة والتوازن بين الاسم والوصف والفاصل.
- النسخة المتجهية المحوّلة إلى مسارات لا تتضمن نصوصاً حية أو صوراً نقطية مضمّنة.
- لم تُجرَ بعد مراجعة قانونية للتشابه أو اختبار طباعة ميداني؛ يلزم ذلك قبل اعتماد الهوية للإنتاج.

## قرارات تحتاج اعتماداً
1. هل نعتمد لون البني الحبر مع العاجي والشامبانيا؟
2. هل يبقى وصف «صالون شعر وأظافر» أم نستبدله بـ«صالون تجميل»؟
3. هل ترغب بأن تكون الحروف أكثر حداثة أو أكثر فخامة/خطّية؟
